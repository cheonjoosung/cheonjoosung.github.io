AutoClick 개인정보 처리방침

시행일: 2026-08-09 · 문의: cjswntjd@gmail.com

AutoClick(이하 “앱”)은 손을 반복적으로 쓰기 어려운 사용자를 위해, 사용자가 직접 지정한 화면 위치를 지정한 간격으로 탭하는 보조 도구입니다. 본 방침은 앱이 어떤 정보를 다루는지와 다루지 않는지를 설명합니다.

1. 수집하지 않는 정보

  • 계정·이름·이메일·전화번호 등 식별 가능한 개인정보 (계정 없음)
  • 화면 내용, 접근성 트리, 다른 앱의 UI 텍스트
  • 탭 좌표 값, 스크립트 이름, 사용 중인 전경 앱 패키지명
  • 위치, 연락처, 사진, 파일

2. 기기에만 저장되는 정보

다음 정보는 기기의 앱 저장소에만 남으며, 저희 서버로 전송되지 않습니다.

  • 사용자가 만든 탭 스크립트(좌표·간격·이름 등)
  • 앱 설정(테마, 언어, UI 크기, 유지 시간 등)

앱을 삭제하면 함께 삭제됩니다.

3. 진단·광고를 위해 외부로 전송되는 정보

3-1. 비정상 종료(크래시) 진단 — Firebase Crashlytics (release 빌드)

  • 목적: 앱 안정성 개선
  • 항목: 기기 모델, OS 버전, 앱 버전, 스택트레이스, 엔진 상태 등 진단 메타데이터
  • 제외: 좌표 값, 스크립트 이름, 전경 앱 패키지명, 사용자 ID
  • 제공처: Google (Firebase Crashlytics)

3-2. 광고 — Google AdMob

  • 목적: 앱 내 배너·전면 광고 표시
  • 항목: 광고 ID(AAID), 대략적 기기·네트워크 정보 등 Google 광고 정책에 따른 항목
  • 제공처: Google (AdMob)
  • 기기 설정에서 광고 ID 재설정·삭제를 할 수 있습니다.

4. 접근성 서비스

앱은 접근성 서비스를 “지정한 위치를 대신 눌러주기” 용도로만 사용합니다. 화면 내용을 읽거나 저장하거나 외부로 보내지 않습니다.

5. 보관 기간

  • 기기 내 데이터: 앱 삭제 시까지
  • 크래시·광고 관련 데이터: 각 제공처(Google)의 정책에 따름

6. 이용자 권리

계정 기반 개인정보가 없어 열람·정정 요청 대상이 거의 없습니다. 기기 내 데이터는 앱 삭제 또는 앱 데이터 삭제로 제거할 수 있습니다. 문의: cjswntjd@gmail.com

7. 방침 변경

AutoClick Privacy Policy

Effective: 2026-08-09 · Contact: cjswntjd@gmail.com

AutoClick helps people who find repetitive tapping difficult by tapping screen locations they choose, at intervals they set. This policy explains what the app does and does not collect.

1. Information we do not collect

  • Accounts, names, emails, phone numbers (no accounts)
  • Screen contents, accessibility trees, or other apps’ UI text
  • Tap coordinates, script names, or foreground app package names
  • Location, contacts, photos, or files

2. Data stored only on the device

  • User-created tap scripts
  • App settings (theme, language, UI size, duration, etc.)

These stay on the device and are removed when the app is uninstalled.

3. Data sent externally

3-1. Crash diagnostics — Firebase Crashlytics (release builds)

  • Purpose: improve stability
  • Data: device model, OS/app version, stack traces, engine state metadata
  • Not included: coordinates, script names, foreground packages, user IDs
  • Processor: Google (Firebase Crashlytics)

3-2. Ads — Google AdMob

  • Purpose: show banner and interstitial ads
  • Data: advertising ID and related signals per Google Ads policies
  • Processor: Google (AdMob)

4. Accessibility service

The accessibility service is used only to perform taps at user-specified positions. It does not read, store, or transmit screen contents.
